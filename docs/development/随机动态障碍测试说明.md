# 随机动态障碍测试说明

本文说明 MuJoCo 动态障碍评测、批量 sweep、指标和复现方法。配置与真机边界见[总说明](避障加动态所有新增修改.md)。以下均使用仿真 geom 障碍，不是相机/点云真机实验。

## 测试口径

动态 evaluator 先扫描 target bank，选出会碰杆的 challenge targets；随后 none（无 CBF 对照）和 geom（CBF）在同一 target 列表和同一障碍轨迹上评测。

- --seed：target 扫描/抽样 seed；比较配置时应固定。
- --obstacle-motion-seed：随机障碍轨迹 seed；相同值与相同参数可复现轨迹。
- 动态 evaluator 的 lookahead 默认 2.0；静态 evaluator 默认 0.0；shared CbfConfig 默认 0.0。

动态场景默认锁直立，使预设位置/速度轨迹可比较。--obstacle-can-fall 仅用于 viewer 观察，不应用于严格统计。

## Motion mode

| 模式 | 作用 | 复现性质 |
|---|---|---|
| random | 连续随机路点运动 | 同一 seed 可复现 |
| random_depart | 先随机运动，再连续让开 | 同一 seed/参数可复现 |
| random_depart_probe | TCP 接近目标后回探 | 触发依赖控制轨迹，适合交互演示 |

motion 默认 none，只有显式 --obstacle-motion 才启动动态障碍。

## 单组动态评测

~~~bash
REPO_ROOT="$(git rev-parse --show-toplevel)"
cd "$REPO_ROOT"

python mujoco/eval_sdf_challenge.py \
  --out-dir logs/eval/check_random_depart_seed43_16 \
  --seed 42 \
  --scan-count 64 \
  --max-challenges 16 \
  --methods none geom \
  --obstacle-motion random_depart \
  --obstacle-motion-amp 0.02,0.02,0.00 \
  --obstacle-motion-period 1.0 \
  --obstacle-motion-seed 43 \
  --obstacle-motion-active-time 2.0 \
  --obstacle-motion-clear-offset 0.18,0.12,0.00 \
  --obstacle-motion-clear-time 2.0 \
  --workspace-sdf-preset dynamic
~~~

该目录包含 challenge_indices.json 与 summary.json。相同 challenge target 顺序可由 play.py --target-indices-file 连续重放。

## 批量 sweep

~~~bash
python scripts/sweep_dynamic_obstacles.py \
  --out-root logs/eval/dynamic_obstacle_sweep \
  --obstacle-seeds 42,43,44,45 \
  --motions random,random_depart \
  --amps 0.02,0.02,0.00 \
  --periods 1.0 \
  --scan-count 64 \
  --max-challenges 16
~~~

sweep 使用 subprocess 调用 mujoco/eval_sdf_challenge.py，默认扫描 2 种 motion × 4 个 obstacle seed，共 8 个场景。它读取每组 summary.json，写出：

~~~text
logs/eval/dynamic_obstacle_sweep/<scenario>/summary.json
logs/eval/dynamic_obstacle_sweep/sweep_summary.csv
logs/eval/dynamic_obstacle_sweep/sweep_summary.md
~~~

扫多组振幅时，--amps 用分号分隔三维向量：

~~~bash
--amps '0.01,0.01,0.00;0.02,0.02,0.00;0.03,0.03,0.00'
~~~

--skip-existing 默认开启；需要重跑已有场景时使用 --no-skip-existing。logs/ 已被 .gitignore 忽略，不提交 summary、CSV 或 Markdown 运行产物。

## 指标

在 summary.json 的 metrics.geom 中重点查看：

| 指标 | 含义 |
|---|---|
| contact_rate | 碰杆局比例，越小越好 |
| reach_2cm_rate | 曾进入目标 2 cm 的比例 |
| safe_reach_2cm_rate | 未碰杆且进入目标 2 cm 的比例 |
| mean_best_dist_m | 各局最佳目标距离均值 |
| mean_end_dist_m | 终止时目标距离均值 |
| mean_max_obs_speed | 障碍最大速度统计 |

无接触不等于完成任务，到达目标也不等于安全完成；应结合 safe_reach_2cm_rate、接触率和距离指标判断。
