# 新手目录地图

这份文档只回答一个问题：打开这个仓库时，先看哪里，哪些先别管。

## 一句话

这个仓库不是一个单纯的 Python 作业，而是一个机器人实验项目。里面同时放了：

- 训练 policy 的代码；
- 电脑仿真的代码；
- 控制真实机械臂的 ROS2 代码；
- 舵机、相机和标定文件；
- YOLO、SAM、AnyGrasp、Orbbec 等外部依赖；
- 每次实验产生的日志和构建产物。

所以目录多是正常的，但不是每个目录都要一起看。

## 现在调实机避障，先看这条线

```text
ros2/scripts/real/run_policy_reach.sh
  -> ros2/soarm100_vision/soarm100_vision/target_segmenter_node.py
  -> ros2/soarm100_vision/soarm100_vision/obstacle_cloud_node.py
  -> ros2/soarm100_vision/soarm100_vision/policy_reach_node.py
  -> mujoco/cbf.py
  -> hardware/tools/run_hardware_controller.py
```

白话解释：

- `run_policy_reach.sh`：总开关，负责启动其他程序；
- `target_segmenter_node.py`：眼睛，把 cup 从图片里抠出来；
- `obstacle_cloud_node.py`：清洁工，把 cup 深度变成障碍物点云；
- `policy_reach_node.py`：主控制，每一轮决定机械臂怎么动；
- `mujoco/cbf.py`：安全员，检查 policy 动作会不会撞；
- `run_hardware_controller.py`：真正和舵机说话。

## 重要词翻译

- 真机：真实桌子上的机械臂。
- 仿真：电脑里的假机械臂。
- 标定：告诉电脑“真实世界”和“代码数字”怎么对应。
- policy：训练出来的大脑，决定下一步怎么动。
- CBF：安全员，拦住危险动作。
- ROS2：机器人程序之间发消息的系统。
- topic：ROS2 里的消息频道。
- mask：黑白图，白色表示 cup 像素。
- 点云：很多 3D 小点，表示 cup 或障碍物表面。
- TCP：夹爪真正干活的点。
- FK：已知关节角，算夹爪在哪里。
- 舵机：机械臂关节里的电机。

## 别一开始看的东西

刚接手时，不要从这些地方开始：

- `mujoco/cbf.py`：数学最重，先知道数据怎么流再看；
- `rl/train.py`：训练主程序，现在调真机避障不需要先看；
- `third_party/`：外部相机依赖，不是项目主逻辑；
- `log/`：日志很多，只有定位问题时再看。

## 最安全的阅读顺序

1. 看 `ros2/scripts/real/run_policy_reach.sh`，只看它启动了哪些 Python 文件。
2. 看 `obstacle_cloud_node.py`，弄懂 `target_only` 和 `all_except_target`。
3. 看 `policy_reach_node.py`，找到 `_control_tick()`。
4. 最后再看 `mujoco/cbf.py` 的 `solve_cbf_correction()`。
